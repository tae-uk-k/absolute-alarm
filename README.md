# 절대 알람

시간표의 첫 수업에 맞춰 준비와 출발을 확인하는 Android 알람 앱입니다. 이 저장소는 **APK 릴리즈 배포용**입니다.

## 설치

**[최신 APK 다운로드](https://github.com/tae-uk-k/absolute-alarm/releases/latest/download/absolute-alarm.apk)** · [릴리즈 목록](https://github.com/tae-uk-k/absolute-alarm/releases)

Android 8.0 이상에서 사용할 수 있습니다. 파일을 열어 Android 설치 안내를 따르세요. 기존 절대 알람이 있다면 삭제하지 말고 같은 앱 위에 업데이트하세요.

0.3.1부터 앱의 **설정 → 업데이트**에서 새 버전을 확인하고 다운로드할 수 있습니다. 처음에는 이 앱의 설치 허용을 켜고, Android 설치 화면에서 설치를 확인해야 합니다. 실행 중이거나 10분 안에 예정된 알람이 있으면 설치를 미룹니다.

앱은 다운로드한 APK의 해시, 앱 식별자, 버전, 기존 앱과의 서명을 확인합니다. GitHub 로그인은 필요 없습니다. 자동으로 앱을 삭제하거나 사용자 확인 없이 설치하지 않습니다.

## 기능

- 요일별 첫 수업과 통학 시간 설정
- 집에 있을 때 준비 확인 진동, 무응답 시 반복 경보
- 준비 중 응답 후 출발 재확인
- 수학·문장 입력·흔들기 기상 미션과 기상 재확인
- 집 Wi-Fi 연결·주변 검색을 이용한 집 감지, 공유기 여러 개 등록/해제

0.4.0부터 오늘 또는 설정 → 집 Wi-Fi에서 공유기를 등록합니다. Wi-Fi를 꺼도 검색하려면 정확한 위치 권한과 기기의 위치 기능·Wi-Fi 검색 설정이 필요합니다. 검색이 실패하거나 집 신호가 없어도 외출로 처리하지 않고 위치 확인과 경보를 유지합니다. 정확한 위치가 집 밖이면 출발 완료로 처리합니다. Wi-Fi 꺼짐 검색은 실제 휴대폰에서 확인이 필요합니다.

시간표와 집 위치, 등록한 공유기 정보는 기기에 저장합니다. 업데이트 화면을 열면 GitHub에 최신 릴리즈를 조회하며, 사용자가 선택한 경우 APK를 다운로드합니다.

## 사용 전 확인

정확한 알람, 알림, 잠금 화면, 위치 권한과 제조사 절전 예외를 설정하세요. 실제 기기에서 소리·진동·잠금 화면 동작을 시험하세요.

전원 꺼짐·방전·앱 강제 종료·권한 해제에서는 울림을 보장할 수 없습니다. 에뮬레이터 검사에서 일부 예약의 소리 시작이 약 5.3초 늦어진 적이 있습니다. 집 밖 확인은 출발 확인이며 학교 도착이나 출석 증명은 아닙니다.

경보 중 다른 음악 앱은 잠시 멈출 수 있습니다. 최대 음량 옵션은 기기 전체 알람 음량에 영향을 주며 기본적으로 꺼져 있습니다. 알라미 전체 기능을 복제한 앱은 아닙니다. 사진·바코드·수면 분석은 현재 포함하지 않습니다.

현재 배포는 기존 개발용 APK와 업데이트 호환성을 유지하는 개인 테스트용 배포입니다. 서명 키가 바뀌면 기존 설치를 유지한 업데이트가 불가능하므로 키를 계속 보관해야 합니다.
