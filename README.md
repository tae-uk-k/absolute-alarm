# 절대 알람

시간표의 첫 수업에 맞춰 준비와 출발을 확인하는 Android 알람 앱입니다. 이 저장소는 **APK 릴리즈 배포용**입니다.

## 설치

**[최신 APK 다운로드](https://github.com/tae-uk-k/absolute-alarm/releases/latest/download/absolute-alarm.apk)** · [릴리즈 목록](https://github.com/tae-uk-k/absolute-alarm/releases)

Android 8.0 이상에서 사용할 수 있습니다. 파일을 열어 Android 설치 안내를 따르세요. 기존 절대 알람이 있다면 삭제하지 말고 같은 앱 위에 업데이트하세요.

0.3.1부터 앱의 **설정 → 업데이트**에서 새 버전을 확인하고 다운로드할 수 있습니다. 처음에는 이 앱의 설치 허용을 켜고, Android 설치 화면에서 설치를 확인해야 합니다. 실행 중이거나 10분 안에 예정된 알람이 있으면 설치를 미룹니다.

앱은 다운로드한 APK의 해시, 앱 식별자, 버전, 기존 앱과의 서명을 확인합니다. GitHub 로그인은 필요 없습니다. 자동으로 앱을 삭제하거나 사용자 확인 없이 설치하지 않습니다.

## 기능

- 요일별 첫 수업과 통학 시간 설정
- 집에 있을 때 준비 확인 진동, 무응답 시 반복 경보
- 준비 중 응답 후 출발 재확인
- 수학·문장 입력·흔들기·QR/바코드 기상 미션과 기상 재확인
- 충전·Wi-Fi 연결·등록한 주변 공유기 신호를 우선하는 집 감지
- 연결할 수 없는 주변 공유기도 여러 개 등록/해제
- 누적 긴급 해제에 따라 2줄·4줄·6줄로 늘어나는 입력 미션
- 수업일 알람 미리 예약과 출발 마감 별도 확인
- 장기 사용 권한 점검과 개편한 화면

0.5.1은 충전 연결, 아무 Wi-Fi 연결, 등록한 집·주변 공유기 최신 감지 중 하나라도 있으면 집으로 판단합니다. 모두 없을 때만 위치를 확인합니다. 따라서 학교·카페·차량에서도 충전/연결 Wi-Fi가 있으면 집으로 처리됩니다. 집 밖 확인은 실제 출석을 증명하지 않습니다.

오늘 또는 설정 → 집·주변 Wi-Fi에서 공유기를 등록합니다. 연결할 수 없는 주변 공유기도 보조로 쓸 수 있습니다. Wi-Fi를 꺼도 검색하려면 정확한 위치 권한과 기기의 위치 기능·Wi-Fi 검색 설정이 필요합니다. 검색 실패·미감지로 외출을 확정하지 않습니다. Wi-Fi 꺼짐 검색은 실제 휴대폰에서 확인이 필요합니다.

QR·바코드는 카메라로 등록한 뒤 기상 알람의 미션으로 선택합니다. 등록한 코드만 해제할 수 있습니다. 긴급 해제는 처음 2줄, 다음 4줄, 이후 6줄처럼 늘어나며 누적 횟수는 재실행·업데이트에 유지됩니다. 날짜별 초기화는 없고 앱 데이터 삭제/재설치 후까지 보존하는 서버 기능은 없습니다.

시간표와 집 위치, 등록한 공유기와 코드의 해시, 긴급 해제 누적 횟수는 기기에 저장합니다. 카메라 영상·사진·코드를 서버에 보내지 않습니다. 업데이트 화면을 열면 GitHub에 최신 릴리즈를 조회하며, 사용자가 선택한 경우 APK를 다운로드합니다.

## 사용 전 확인

설정 → 장기 사용 점검에서 정확한 알람, 알림, 잠금 화면, 위치 권한, 미사용 앱 자동 중지 해제와 제조사 절전 예외를 확인하세요. 실제 기기에서 소리·진동·잠금 화면 동작을 시험하세요. 수업일 보호를 켜야 시간표 확인이 동작합니다. 수업 없는 날은 출석 확인을 예약하지 않습니다.

전원 꺼짐·방전·앱 강제 종료·권한 해제에서는 울림을 보장할 수 없습니다. 에뮬레이터 검사에서 일부 예약의 소리 시작이 약 5.3초 늦어진 적이 있습니다. 집 밖 확인은 출발 확인이며 학교 도착이나 출석 증명은 아닙니다.

경보 중 다른 음악 앱은 잠시 멈출 수 있습니다. 최대 음량 옵션은 기기 전체 알람 음량에 영향을 주며 기본적으로 꺼져 있습니다. 알라미 전체 기능을 복제한 앱은 아닙니다. 사진 미션·수면 분석은 현재 포함하지 않습니다.

현재 배포는 기존 개발용 APK와 업데이트 호환성을 유지하는 개인 테스트용 배포입니다. 서명 키가 바뀌면 기존 설치를 유지한 업데이트가 불가능하므로 키를 계속 보관해야 합니다.
